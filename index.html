Как пользоваться

1. Переместите карту к нужному городу Казахстана.
2. Нажмите A или B — список служб загрузится только для этой области.
3. Выберите службу или поставьте точку на карте.
4. Нажмите «Построить маршрут».

Карта охватывает Казахстан. Загрузка служб выполняется по запросу, а их значки показываются только для выбранных точек A и B. 2ГИС/OSRM строят маршрут по доступным дорожным данным.
